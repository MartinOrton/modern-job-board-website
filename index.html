Features

Everything you need to run a job board

From listings and private CVs to freemium plans, monetization, and a Business-grade API. Built as a WordPress plugin you own and host.

Frontend Job Submission

Employers post and edit jobs from the frontend. Company profiles, featured listings, auto expiration, and optional Pro custom fields on the form.

AJAX Search & Pretty URLs

Filter by keyword, location, category, type, and company with no full page reloads. Pretty /jobs/ routes for shareable search results.

Employer & Candidate Accounts

Registration, dedicated login shortcodes, and dashboards for both audiences. Application pipeline statuses, analytics, and one-click apply from a stored CV.

Private Resumes & CVs

Resumes live under wp-content/mjb-private/, not the Media Library. Authenticated, permission-checked downloads for employers only.

WooCommerce Monetization (Pro)

Pay-per-post, job credit packages, paid CV unlocks, and time-based access. Use any WooCommerce payment gateway. You keep the revenue on your store.

Gutenberg Blocks

Jobs, forms, dashboards, registration, and login as native blocks. Build pages in the editor without shortcode syntax.

SEO Ready

Automatic Schema.org JobPosting markup for Google for Jobs, plus optional Maps embeds on job pages.

Custom Fields & Imports (Pro)

Admin builder for job and application fields. CSV/XML import and export, remote feed URLs, and scheduled imports without writing code.

REST API, Feeds & Webhooks (Business)

Public job search (v1), authenticated employer/candidate API (v2), XML feed syndication, and outbound webhooks with HMAC signing and a retry queue.

Developers

Built for extensibility

REST API (v1 + authenticated v2), XML feeds, webhooks with retry queue, and hooks for deep customization. API, feeds, and webhooks ship with the Business plan.

REST API v1 & v2

Public job search, employer applications and analytics, and candidate profile endpoints. Application passwords over HTTPS. Ownership-scoped for employers.

XML Feed & Webhooks

Syndicate at /feed/job-listings. Outbound webhooks for applications and jobs, optional HMAC signature, and a retry queue when endpoints fail.

Actions & Filters

Hooks for job queries, form submissions, license plan overrides, webhook payloads, and more. Extend without editing plugin core files.

// Public job search
GET /wp-json/mjb/v1/jobs

// Employer applications (auth)
GET /wp-json/mjb/v2/applications

// Response (v1 sample)
[
  "id": 123,
  "title": "Senior Developer",
  "company": "Acme Inc",
  "location": "Remote"
]

// Customize listing queries
add_filter('mjb_job_listing_query_args', function($args) {
  $args['orderby'] = 'date';
  return $args;
});
