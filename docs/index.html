Modern Job Board v0.9.0-beta.1

Install the plugin, create frontend pages, and extend it with blocks, shortcodes, REST, and webhooks.

Quick start

  1. Upload and activate the plugin.
  2. Open Modern Job Board → Setup and create missing pages.
  3. Configure Settings for listings, security, and integrations.
  4. Post a test job and submit a test application.

Shortcodes & blocks

  • [mjb_jobs] — searchable listings
  • [mjb_job_form] — employer submission form
  • [mjb_dashboard] — employer dashboard
  • [mjb_candidate_dashboard] — candidate profile
  • [mjb_employer_registration] / [mjb_candidate_registration]

All shortcodes are also available as Gutenberg blocks under Modern Job Board.

REST API

Public search:

GET /wp-json/mjb/v1/jobs/search/in/remote/category/engineering/type/full-time/

Authenticated employer/candidate endpoints live under /wp-json/mjb/v2/. REST API access requires the Business plan.

Feeds & webhooks

  • XML feed: /feed/job-listings
  • Webhook events: application.submitted, application.status_updated, job.submitted
  • Optional HMAC signing via X-MJB-Signature

Plans & licensing

Modern Job Board is a proprietary freemium plugin. Start free, then upgrade for monetization, imports, and API features — or choose Complete Site for a done-for-you build.

  • Free — up to 10 active jobs, core board, community support
  • Pro — unlimited jobs, WooCommerce, custom fields, import/export
  • Business — REST API, XML feeds, webhooks, priority support
  • Complete Site — full site build + Business included for year one
